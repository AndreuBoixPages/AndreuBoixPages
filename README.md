# Andreu Boix Pagès

Biomedicine graduate working at the intersection of computational structural biology and machine learning. Currently at the University of Cambridge (Vendruscolo lab), working on machine learning models for biomolecular  binding.

### What I've worked on

**Ries lab, Max Perutz Labs, Vienna (2026)**
Deep learning (Swin Transformers, PyTorch) to extract geometric parameters directly from Single Molecule Localization Microscopy (SMLM) data, trained on simulated images. I also contributed two plugins to [SMAP](https://github.com/jries/SMAP), the lab's analysis software:
- Automatic detection of clathrin-coated pit sites ([pull request #34](https://github.com/jries/SMAP/pull/34))
- Distance-binned averaging of endocytic sites, to reconstruct the timeline of endocytosis

**Serrano lab, Centre for Genomic Regulation (CRG), Barcelona (2023–2025)**
Development and validation in C++ of a fragment-based protein–protein interface generator within the ModelX toolsuite (FoldX force field). Bachelor's thesis.

**iGEM 2025, Barcelona-UIC team (Bronze Medal)**
Dry lab lead in a project towards an aptamer-based early diagnostic test for ALS.
